# Mahakal Outline Drawing using Python Turtle 🐍🕉️

This project converts a standard image of Lord Shiva into a beautiful neon-themed line art animation using Python's **Turtle** graphics and the **Pillow (PIL)** library for edge detection. 

---

## 🚀 Features
- **Edge Detection:** Uses `ImageFilter.FIND_EDGES` to automatically trace the outline of the image.
- **Custom Color Mapping:** Draws the moon in solid **White** and the rest of the deity in a striking **Neon Blue** color.
- **Fast Rendering:** Optimized using `screen.tracer(0)` for smooth and quick drawing performance.

---
